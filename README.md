# 🌱 Codetree-Study

> Codetree를 활용한 코딩테스트 & 알고리즘 학습 기록

코딩테스트 준비를 위해 **Codetree에서 문제를 풀이하고 기록하는 저장소**입니다.  
해결한 문제와 코드는 Codetree 연동을 통해 GitHub에 자동으로 업로드됩니다.

---

## 🎯 목표

- 꾸준한 알고리즘 문제 풀이
- 코딩테스트 문제 해결 능력 향상
- 알고리즘 및 자료구조 학습
- 다양한 문제 유형 경험
- 문제 풀이 기록 관리

## 🔄 Auto Commit

Codetree에서 문제를 해결하면 풀이 코드가 GitHub에 자동으로 기록됩니다.

```text
[Passed] 문제명
```

따로 풀이 코드를 옮기지 않고  
**문제를 풀어온 과정 자체를 꾸준히 기록하는 것**을 목표로 합니다.
